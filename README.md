# Java Mini Project

A Java 21 Maven project containing QR-code and HTTP client related dependencies.

## Tech Stack

- Java 21
- Maven
- ZXing
- OkHttp
- MySQL Connector/J

## Build

Run the Maven build with:

```bash
mvn clean verify
```

Generated Maven output is placed in the `target/` directory.

## Project Structure

- `src/` - application source code
- `pom.xml` - Maven project configuration
- `demo.png` / `web.png` - project reference images

## Notes

Keep IDE metadata and build output out of new commits by using the standard Java/IntelliJ ignore rules.
